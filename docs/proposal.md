# Приём заказов без обзвона: предложение

Рабочая версия документа: https://claude.ai/code/artifact/a2be5fae-40ba-4831-961d-326723c7d71e

## Проблема

Менеджер тратит 4–6 часов в день на обзвон, а производство всё равно получает заказы день в день, хотя на продукцию ему нужно 3–5 дней.

- **Время.** Каждый день менеджер обзванивает 20–50 клиентов: магазины, общепит, оптовиков. На одного клиента уходит 5–10 минут.
- **Двойной ввод.** Заказ сначала записывают на листок, потом вручную переносят в заявку в 1С.
- **Ошибки в заявках.** При переносе можно выбрать не то наименование или не тот холодильник для отгрузки.
- **Забытые клиенты и заказы.** Иногда менеджер забывает позвонить. Заказы, принятые за 8 дней, держатся только в памяти.
- **Спешка на производстве.** Охлаждённые полуфабрикаты и колбасы делают за 3–5 дней, а заказы приходят в день отгрузки.
- **Возвраты без учёта.** Неизвестно, кто, что и почему возвращает.

## Решение

Клиенты сами оформляют заказ через веб-форму по ссылке, а менеджер занимается только исключениями.

| Что делает помощник | Какую проблему решает |
| --- | --- |
| Одна ссылка на форму для любого мессенджера | Заказы собираются в одном месте |
| Менеджер на звонке вносит заказ в ту же форму | Нет двойного ввода |
| Товар выбирается только из списка наименований 1С | Нельзя выбрать не то наименование |
| Холодильник подставляется сам: у каждого наименования свой | Не перепутают склад |
| Постоянному клиенту подставляется прошлый заказ | Заказ занимает минуту |
| Напоминание клиенту заранее | Никого не забывают |
| У заказа есть дата отгрузки, заказы хранятся наперёд | Заказ за 8 дней не потеряется |
| Пометка «поздний заказ» | Решает менеджер, производство не узнаёт в последний момент |
| Сводка для производства по дням и позициям | План на 3–5 дней вперёд |
| Готовый файл заявок для загрузки в 1С | Заявку не нужно набирать руками |
| Кнопка «Возврат»: что, сколько, почему | Появляется статистика возвратов |

## Связь с 1С 7.7

Главное улучшение после пилота — загрузка заявок в 1С из файла. На пилоте базу не трогаем: менеджер переносит заявки с готовой сводки.

Вопросы специалисту 1С:

- [ ] Можно ли выгрузить в Excel клиентов и товары, у товаров — с холодильником?
- [ ] Можно ли загружать заказы из файла (Excel, CSV, DBF)?
- [ ] Сколько стоит такая доработка и сколько займёт времени?
- [ ] Есть ли планы переходить на 1С 8?

## План пилота

5–10 постоянных клиентов, 3–4 недели.

1. **Подготовка (1 неделя).** Выбрать клиентов, выгрузить их позиции из 1С, замерить время на обзвон.
2. **Запуск формы.** Отправить клиентам ссылку и инструкцию.
3. **Работа (2–3 недели).** Заказы через форму, сводка производству, учёт возвратов.
4. **Итоги.** Сравнить цифры «до» и «после», решить, расширять ли.

## Что замеряем

| Показатель | Цель пилота |
| --- | --- |
| Время менеджера на клиентов пилота | Вдвое меньше |
| Заказы день в день | Не больше 10% |
| Заказы за 3 дня и раньше | Не меньше 70% |
| Забытые клиенты и заказы | 0 |
| Возвраты с причиной | 100% |
| Клиенты, заказывающие через форму | Не меньше 7 из 10 |

# Приём заказов (демо)

Демо помощника для приёма заказов на мясном производстве: клиенты сами оформляют заказ по ссылке, менеджер занимается только исключениями.

Все клиенты, товары и заказы выдуманы. Данные хранятся только в браузере (`localStorage`) и никуда не отправляются.

## Что в демо

- **Заказ клиента**: подставляется прошлый заказ, товар выбирается только из списка, холодильник подставляется сам. Если до отгрузки меньше дней, чем нужно на производство, заказ помечается как поздний.
- **Менеджер**: поздние заказы и заказы с комментарием ждут решения. Есть список клиентов без заказа на неделю, приём заказа по телефону в ту же форму и заявки для 1С с выгрузкой в CSV.
- **Производство**: сводка по дням и позициям на 7 дней вперёд.
- **Возвраты**: запись в три поля и статистика по причинам, товарам и клиентам.

Личная ссылка клиента имеет вид `index.html#client=c1`.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны. Для показа по ссылке подойдёт GitHub Pages.
